```release-note:breaking-change
resource/kubernetes_pod_v1: migrate to Plugin Framework. Change `resources { ... }` to `resources = [{ ... }]` inside regular and init containers, and use list assignments for `spec.image_pull_secrets` and `spec.readiness_gate`. The stored list shapes, resource name, and `namespace/name` ID are unchanged; these syntax edits do not require Pod replacement or re-import. See the Pod Plugin Framework migration guide.
```

```release-note:breaking-change
resource/kubernetes_pod_v1: retain configured resource quantity strings on creation instead of SDKv2 normalization (for example, CPU `"0.5"` instead of `"500m"`). Existing equivalent state values are preserved; imports use API spelling. Allocations are unchanged.
```

```release-note:enhancement
resource/kubernetes_pod_v1: support `moved` blocks from the deprecated `kubernetes_pod` resource on Terraform 1.8 and later.
```
