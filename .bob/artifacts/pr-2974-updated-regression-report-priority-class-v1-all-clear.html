Fixes Applied

BF-1 FIXED — Plan-time validator for missing metadata block
File changed: priority_class_v1.go  |  Interface added: resource.ResourceWithConfigValidators

Added ConfigValidators() to PriorityClassV1 returning a metadataRequiredValidator. The validator decodes the plan config and adds a diagnostic error when len(config.Metadata) == 0 — before any CRUD method is reached. Matches SDKv2's Required: true behaviour.

Before (crash)
Plan: 1 to add, 0 to change, 0 to destroy
→ Apply: panic: index out of range [0] with length 0
Provider process killed
After (plan-time error)
Error: Missing required block
A metadata block is required for kubernetes_priority_class_v1.
Add a metadata { name = "..." } block to your configuration.
Plan exits 1 — no apply, no crash 
// priority_class_v1.go — new method
func (r *PriorityClassV1) ConfigValidators(_ context.Context) []resource.ConfigValidator {
    return []resource.ConfigValidator{&metadataRequiredValidator{}}
}

func (v *metadataRequiredValidator) ValidateResource(ctx context.Context,
    req resource.ValidateConfigRequest, resp *resource.ValidateConfigResponse) {
    var config PriorityClassModel
    resp.Diagnostics.Append(req.Config.Get(ctx, &config)...)
    if len(config.Metadata) == 0 {
        resp.Diagnostics.AddError("Missing required block", "A metadata block is required...")
    }
}
BF-2 FIXED — UseStateForUnknown() added to metadata.name
File changed: priority_class_v1_schema.go:65  |  Plan modifier added before RequiresReplace()

When generate_name is used and name is not in config, Framework previously left name as unknown in the plan — causing RequiresReplace to fire on every secondary change (labels, annotations, description). Adding UseStateForUnknown() preserves the server-assigned name from state, so secondary changes produce in-place updates as in SDKv2.

Before (wrong replacement)
~ name = "probe4-genname-jmz2m"
      → (known after apply) # forces replacement
Plan: 1 to add, 0 to change, 1 to destroy
After (correct in-place update)
+ labels = { "team" = "platform" }
  name = "probe4fix-jmjr4" (preserved)
Plan: 0 to add, 1 to change, 0 to destroy 
// priority_class_v1_schema.go — metadata.name plan modifiers
PlanModifiers: []planmodifier.String{
    // UseStateForUnknown preserves the server-assigned name when generate_name
    // is used — prevents spurious replacement on secondary changes.
    stringplanmodifier.UseStateForUnknown(),  // ADDED
    stringplanmodifier.RequiresReplace(),
},
