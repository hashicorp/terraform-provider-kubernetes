```release-note:note
`resource/kubernetes_horizontal_pod_autoscaler_v1`: Migrated from SDKv2 to the Plugin Framework, preserving configuration syntax and the `autoscaling/v1` API. `moved` blocks from the deprecated `kubernetes_horizontal_pod_autoscaler` resource are supported with Terraform 1.8 or later when its state has no `metric` or `behavior` blocks. Explicit empty metadata maps may require a one-time in-place update, and a `terraform plan -refresh=false` immediately after upgrading may show a one-time in-place update normalizing an unset `generate_name` or `scale_target_ref.api_version` from `""` to null; neither changes nor replaces the autoscaler. See the Plugin Framework upgrade guide for details.
```

```release-note:breaking-change
`resource/kubernetes_horizontal_pod_autoscaler_v1`: Setting both `metadata.name` and `metadata.generate_name` is now rejected during plan, including `generate_name = ""`. Earlier versions allowed it, but the Kubernetes API ignores `generate_name` whenever `name` is set. To keep the existing autoscaler, remove `generate_name` if it is empty (`""`); otherwise remove `name` and keep `generate_name`. Making the other change replaces the autoscaler.
```

```release-note:breaking-change
`resource/kubernetes_horizontal_pod_autoscaler_v1`: `null` is no longer accepted as a value in `metadata.labels` or `metadata.annotations`. Earlier versions accepted it and silently dropped the entry.
```

```release-note:note
`resource/kubernetes_horizontal_pod_autoscaler_v1`: Import IDs require a non-empty namespace and name.
```
