```release-note:enhancement
`kubernetes_ingress_v1`, `kubernetes_ingress_class_v1`, `kubernetes_network_policy_v1`: Migrate managed resources to Plugin Framework while retaining their resource types, configuration syntax, state schema version, and resource identity. Add Terraform 1.8+ moved-block support from the deprecated ingress class and network policy aliases. The incompatible v1beta1 `kubernetes_ingress` alias does not support this move.
```

```release-note:note
`kubernetes_ingress_v1`, `kubernetes_ingress_class_v1`, `kubernetes_network_policy_v1`: Explicitly empty metadata labels or annotations previously stored as null can require a one-time state-only update to empty maps. This exception must not cause Kubernetes API writes or replacement, and the following plan must be empty; it does not extend to omitted metadata, TLS hosts, or other fields.
```

```release-note:note
`kubernetes_network_policy_v1`: Explicit `match_labels = {}` and `match_expressions[*].values = []` (only `Exists`/`DoesNotExist`) previously stored as null can require a one-time state-only update. The selector paths are `spec.pod_selector`, `spec.ingress[*].from[*].namespace_selector`, `spec.ingress[*].from[*].pod_selector`, `spec.egress[*].to[*].namespace_selector`, and `spec.egress[*].to[*].pod_selector`. The update must preserve the UID and full specification, cause no Kubernetes API writes or replacement, and leave the next plan empty. Omitted maps/collections and `ip_block.except` are not included.
```
